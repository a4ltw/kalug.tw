# KaLUG Media Kit

Kaohsiung Linux User Group (KaLUG) 的宣傳素材。歡迎用來做活動宣傳、社群貼文、簡報。

## 檔案

| 檔案 | 尺寸 | 用途 |
|---|---|---|
| `kalug_banner.png` | 5669 × 2268 | 橫幅（高畫質），印刷或大型輸出 |
| `kalug_banner.jpg` | 5669 × 2268 | 橫幅（較小檔案），網頁、社群封面 |
| `kalug_icon_1000.png` | 1000 × 1000 | 方形圖，社群大頭貼、活動頁 |
| `kalug_icon_250.png` | 250 × 250 | 方形圖，小尺寸需求 |
| `source/kalug_banner.svg` | — | 橫幅原始檔（Inkscape） |
| `source/kalug_icon.svg` | — | 方形圖原始檔（Inkscape） |

SVG 內嵌了點陣圖，所以放大不會比 PNG 更清楚；它的用途是方便修改文字與排版。
文字使用 Noto Sans Bold，修改前請先安裝該字型。

## QR code

圖中的 QR code 連結到 KaLUG 的入口頁。修改設計時請直接沿用原圖，不要重畫；改完請用手機掃過確認。
